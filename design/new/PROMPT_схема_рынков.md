Задача: снять схему авторынка с карты так же, как сняли схему рынка Кудайберген, и отдать её одним JSON на рынок.

Рынки (центр по OpenStreetMap, lat, lon):
- «Геология», ул. Профсоюзная, Бишкек: 42.886242, 74.520709 (≈600 м к северо-западу от рынка Кудайберген)
- «Дордой Моторс», ул. Патриса Лумумбы, 302, Бишкек: 42.872913, 74.528546
- «Дордой», ул. Жанбо уулу Кадыке, Бишкек: 42.938564, 74.620484 (большой, ~79 га; если не помещается в один снимок — сначала только авторяды/автозапчасти, остальное отметь блоками)

Делай по одному рынку. Для каждого:

1. Открой Яндекс Карты (yandex.kg/maps) на точке рынка, слой «Спутник». Подбери масштаб, чтобы весь рынок занял почти весь экран, и больше камеру не двигай.
2. Сделай скриншот карты и запиши его ширину и высоту в пикселях. Все координаты дальше — пиксели ЭТОГО скриншота: начало в левом верхнем углу, ось Y вниз. Так снята схема Кудайбергена («пиксели схемы рынка (Яндекс-скрин 1376x1426), ось Y вниз»).
3. Опорные GPS-точки (anchors), минимум 4, лучше 5–6, по углам и краям рынка, на чётких местах (угол забора, ворота, угол крыши). Для каждой: правый клик → «Что здесь?» → lat, lon, плюс x, y этой точки на скриншоте и короткая подпись. Точки не на одной линии.
4. Масштаб metersPerPx: линейкой Яндекса измерь длинную сторону рынка в метрах и раздели на её длину в пикселях.
5. Обведи по снимку:
   - boundary — внешний контур рынка, полигон [[x,y], …] по часовой стрелке;
   - rows — ряды контейнеров. Для каждого ряда: code (как его называют на рынке: «1», «14», «А»; не знаешь — нумеруй по порядку и отметь в notes), label («Ряд 14»), type: ROW (горизонтальный), VROW (вертикальный) или STALL (открытые места/жайма), sortOrder (0, 1, 2…), geometry: { axis: [[x1,y1],[x2,y2]] — ось ряда вдоль середины, polygon: 4 угла ряда, halfWidth — половина ширины ряда в пикселях };
   - passages — проходы и проезды между рядами: { points: [[x,y], …] по середине прохода, width — ширина в пикселях }. Проходы должны соединяться друг с другом и со входами — по ним строится маршрут;
   - entrances — въезды и входы: { x, y, label } («Главный въезд», «Вход с Профсоюзной»);
   - blocks — всё, что не ряд: { x, y, w, h, label, kind }, kind: shop (СТО/мастерские), admin (администрация), anon (здание без названия);
   - pois — парковка, туалет, кафе, если видно: { x, y, label, kind }.
6. Посчитай контейнеры в каждом ряду по сторонам (сколько коробок с северной/южной или западной/восточной стороны) — containerCounts.

Ответ — один JSON на рынок, без комментариев внутри:

{
  "market": "GEOLOGIYA" | "DORDOI_MOTORS" | "DORDOI",
  "source": "Яндекс Карты, спутник, скриншот WxH, дата",
  "imageWidth": 0, "imageHeight": 0,
  "metersPerPx": 0.0,
  "anchors": [{ "lat": 0, "lon": 0, "x": 0, "y": 0, "label": "" }],
  "boundary": [[0, 0]],
  "blocks": [{ "x": 0, "y": 0, "w": 0, "h": 0, "label": "", "kind": "anon" }],
  "passages": [{ "points": [[0, 0], [0, 0]], "width": 0 }],
  "entrances": [{ "x": 0, "y": 0, "label": "" }],
  "pois": [],
  "streets": [],
  "labels": [],
  "rows": [{ "code": "1", "label": "Ряд 1", "type": "ROW", "sortOrder": 0,
             "geometry": { "axis": [[0, 0], [0, 0]], "polygon": [[0, 0], [0, 0], [0, 0], [0, 0]], "halfWidth": 0 } }],
  "containerCounts": [{ "row": "1", "NORTH": 0, "SOUTH": 0 }],
  "notes": "что не разглядеть со спутника, где коды рядов придуманы, что проверить на месте"
}

Правила:
- Не выдумывай: что не видно на снимке — в notes, а не в данные.
- Коды рядов, которые ты придумал сам, перечисли в notes — их сверят на рынке.
- Сохрани скриншот рядом с JSON (тем же именем, .png) — по нему будут проверять схему.
- Проверь себя: все точки внутри скриншота, ряды внутри boundary, каждый проход соединён с другим проходом или входом.
